# Lab 13 — Discipline-Specific Agents

**Skill:** Deep Research · **Worklet mapping:** A domain worklet for different engineering disciplines, not one narrow fixed topic.

## What this demonstrates

The Trend & Gap Advisor covers six fields — CS/AI/ML, ECE, EEE, Mechanical, Civil, Cloud/DevOps — ranking topics by measured growth (papers in the last 3 years ÷ the 3 before), not the model's opinion. A confirmed pick hands straight into a full pipeline run under one run id.

## Why this is the real evidence, not a toy

The example gap statement the advisor produced live — *"what specific similarity exists between fake images generated by GANs and those from diffusion models"* — came from real publication data, not a seeded example.
